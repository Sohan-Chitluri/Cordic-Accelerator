## 1. Canonical Vector Sets

All vector files begin with a single header line containing the integer vector count $N$, followed by $N$ stimulus lines. Two file formats are provided:
- **`.mem` format (8 fields):** `x_in y_in z_in cfg_saturate exp_x exp_y exp_z exp_ovf` (expected outputs evaluated at baseline $N_{\text{iter}}=8$, $FRACT\_W=12$, $WIDTH=16$).
- **`.raw` format (4 fields):** `x_in y_in z_in cfg_saturate` (pure input stimulus, parameterized across arbitrary iteration configurations).
- Extensionless aliases (`V_dir`, `V_rand`, `V_full`) mirror the `.mem` files.

### Vector Contents Description
- **`V_dir` (120 vectors):** Generated by `directed_cases()` in `phase0/gen_bitexact_vectors.py`:
  - 8 angle quadrant boundaries $\times$ unit vectors at `XY_LIMIT` (both saturate modes: 16 cases).
  - 49 Cartesian grid combinations across `{-32768, -6000, -1, 0, 1, 6000, 32767}` with $z=0^\circ$ (both saturate modes: 98 cases).
  - 3 extreme saturation and MIN_NEG negation-overflow edge cases (both saturate modes: 6 cases).
- **`V_rand` (800 vectors):** Uniform pseudo-random sampling across the full 16-bit signed domain `[-32768, 32767]` for $x, y, z$ with random Boolean `cfg_saturate` distribution, seeded with `0xB17E`.
- **`V_full` (920 vectors):** Exact concatenation of `V_dir` (lines 1..120) and `V_rand` (lines 121..920). Byte-identical to `phase0/vectors/bitexact_check_iter8.mem`.

## 2. Reconciliation of Historical Vector Sets

Three distinct test vector set sizes appear across project documentation and logs: **4,120**, **920**, and **610**. Their composition, origin, and specific usage are reconciled below:

```
+---------------------------------------------------------------------------------------------------+
| Historical Set Reconciliation                                                                     |
+-------------------+-------------+--------------------+--------------------------------------------+
| Set Size          | PRNG Seed   | Primary File Path  | Purpose & Where Used                       |
+-------------------+-------------+--------------------+--------------------------------------------+
| 4,120 vectors     | 0xB17E      | phase0/vectors/    | Phase 0 RTL-vs-Golden Bit-Exact Gate       |
| (120 dir + 4000)  |             | bitexact_check.mem | Full baseline verification (4120/4120 pass)|
+-------------------+-------------+--------------------+--------------------------------------------+
| 920 vectors       | 0xB17E      | vectors/V_full.mem | Phase 0b/0c Parametric Sweeps & GL Power   |
| (120 dir + 800)   |             | (and iter*.mem)    | Gate-level switching activity & cosim      |
+-------------------+-------------+--------------------+--------------------------------------------+
| 610 vectors       | 0x9E3779B9  | phase0/sweep.py    | Phase 0/0b/0c Floating-Point Error Sweeps  |
| (110 dir + 500)   | (real-unit) | (in-memory)        | RMS & max error vs ideal float sin/cos     |
+-------------------+-------------+--------------------+--------------------------------------------+
```

### 1. The 4,120-Vector Set
- **Composition:** 120 directed cases (`directed_cases()`) + 4,000 random cases drawn with PRNG seed `0xB17E`.
- **Source File:** `phase0/vectors/bitexact_check.mem` (164,503 bytes).
- **Where Used:**
  - **Phase 0 Item 1 (`PROGRESS.md` §1):** Used for the initial large-scale bit-exact cosimulation between `tb/golden_model.py` (`CordicGoldenModel`) and the frozen baseline Verilog RTL (`tb/phase0_cosim_tb.sv` under Verilator).
  - All 4,120 vectors completed with **0 mismatches**, conclusively proving golden model equivalence on the frozen baseline.

### 2. The 920-Vector Set
- **Composition:** 120 directed cases (`directed_cases()`) + 800 random cases drawn with PRNG seed `0xB17E`.
- **Relationship to 4,120 Set:** The 920 set is the **exact prefix** of the 4,120 set. Vectors 1..120 are identical directed cases, and vectors 121..920 are identical to the first 800 random vectors of the 4,120 set.
- **Source Files:** `phase0/vectors/bitexact_check_iter{4,6,8,9,10,11,12,14,16}.mem` (each sharing identical inputs `(x, y, z, sat)` with expected outputs tailored to the respective iteration count).
- **Where Used:**
  - **Phase 0b (§1, §4):** Parametric iteration sweep RTL verification across `ITERATIONS` $\in \{8, 10, 12, 14, 16\}$ ($5 \times 920 = 4,600$ vectors, 0 mismatches).
  - **Phase 0c (§2):** Fixed-design reference family regression check (`Fixed-4`, `Fixed-8`, `Fixed-11`, `Fixed-12`).
  - **Task 1 (Power Split Feasibility Gate):** Gate-level post-route logic simulation (`tb/gl_power_sim_tb.sv`) across `Fixed-4`, `Fixed-8`, and `Fixed-11` to dump VCD switching activity for annotated OpenSTA power extraction.

### 3. The 610-Vector Set
- **Composition:** 110 directed real-unit vectors ($11\text{ angles} \times 5\text{ magnitudes} \times 2\text{ saturate modes}$) + 500 uniform random vectors in real-unit floating-point space ($x, y \in [-1.5, 1.5]$, $z \in [-1.7433, 1.7433]\text{ rad}$), drawn with PRNG seed `0x9E3779B9`.
- **Source:** Defined programmatically in `phase0/sweep.py` (`RANDOM_REAL_VECS` and `directed_real_vecs()`) and `phase0/sweep_b.py`.
- **Where Used:**
  - **Phase 0, Phase 0b, and Phase 0c Numerical Sweeps:** Used to benchmark algorithm error (max absolute error and RMS error) against **exact double-precision floating-point rotation** (`math.sin` / `math.cos`).
  - By evaluating in real floating-point units before quantization, this pool isolated algorithmic iteration truncation and gain ($K$) errors from fixed-point container clamping effects, establishing the mode thresholds (0.10, 0.01, 0.003, 0.001) and identifying the 12-bit quantization floor (~0.0013).
